# PHARMA CLINICAL INTELLIGENCE PWA

Versi 1.0.0 — media pendidikan farmakologi klinis.

## Modul
- Dashboard pembelajaran
- Farmakokinetik ADME dan kalkulator ilustrasi waktu paruh
- Farmakodinamik
- Peta sistem organ
- Database 12 monografi ringkas obat
- Latihan pasangan interaksi obat terpilih
- Simulasi pembelajaran klinis fiktif
- Monitoring terapi dan checklist
- Studi kasus, glosarium, dan referensi ilmiah
- PWA dengan cache offline dasar

## Batasan keselamatan
Aplikasi ini adalah media pendidikan, bukan alat diagnosis, bukan sistem pendukung keputusan klinis tervalidasi, dan bukan sumber dosis atau resep individual. Contoh interaksi dan monografi tidak komprehensif. Jangan masukkan data identitas atau informasi kesehatan pasien nyata. Selalu verifikasi informasi obat dan pedoman klinis terkini melalui sumber resmi serta tenaga kesehatan berwenang.
